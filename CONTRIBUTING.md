# Contributing to Chuga Chocho

Thanks for wanting to help! This is a small, friendly project — a learning train game for little kids.

## Ground rules (please keep it simple)

- **No frameworks, no build step to run.** Plain HTML, CSS, JavaScript, and SVG. The game must always run by opening `play/index.html` directly. This keeps it approachable for beginners and easy to host for free.
- **Keep it kid-safe and gentle.** No losing, no scary sounds, no ads, no tracking, no data collection.
- **Everything is spoken.** New text that a child sees should also be narrated (see `play/js/speech.js`).
- **Accessibility & big touch targets.** Assume small fingers on a tablet.

## Good first contributions

- **Translations** — add a language by adding a dictionary (English and Polish exist; the structure is designed so a new language is *data*, not code).
- **New locations** — add a US state/city scene (art + a scenery definition).
- **Art** — flat storybook-style SVG for backgrounds and trains.
- **Bug fixes & polish.**

## Workflow

1. Fork and branch from `main`.
2. Read `CLAUDE.md` and `DESIGN.md` first — they define the plan and conventions.
3. Make your change; test by opening the game locally.
4. Open a pull request describing what you changed and why.

## Questions

Open an issue — happy to help.
